# FizzBuzz with a Twist

## Challenge
Write a Go program that prints the numbers from 1 to 30. For multiples of 3, print "Fizz" instead of the number. For multiples of 5, print "Buzz". For numbers which are multiples of both 3 and 5, print "FizzBuzz". Additionally, for any number that is a prime, print "Prime" after the number or word.

### Example Output (partial)
```
1
2 Prime
Fizz Prime
4
Buzz Prime
Fizz
7 Prime
8
Fizz
Buzz
11 Prime
Fizz
13 Prime
14
FizzBuzz
...
```
